# 3地点お天気ナビ（無料試作版）

スマホ向けのPWA試作です。初期地点は八千代市、志村坂上、京橋（東京）です。

## データについて
- Open-Meteo Forecast API と Geocoding API を使用します。
- 無料APIは非商用利用向けです。出典表示（Open-Meteo / CC BY 4.0）を残してください。
- 日本気象協会のtenki.jp予報ではありません。予報結果が異なる場合があります。
- 商用利用や公開規模を拡大する場合は、データ提供元の最新の利用条件を確認してください。

## PCで動作確認
1. ZIPを展開します。
2. Python 3がインストールされたPCで、フォルダ内を開いて次を実行します。
   `python -m http.server 8000`
3. ブラウザで `http://localhost:8000` を開きます。

HTMLファイルを直接ダブルクリックしても、APIやPWAの一部機能が正常に動かない場合があります。

## スマホで使う
スマホのホーム画面に追加するには、HTTPS対応のWebサーバーに配置してください。PCのlocalhostはスマホからそのまま開けません。GitHub Pagesなどに公開する場合は、リポジトリを公開することになるため、個人情報や秘密情報を含めないでください。
